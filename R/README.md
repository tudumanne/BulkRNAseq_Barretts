## Downstream analyses using R

This directory contains the R scripts used for the downstream analyses. 

### R packages

The following packages were used alongside standard libraries.

| Package | Version |
|----------|---------|
| DESeq2 | v1.46.0 |
| clusterProfiler | v4.14.6 |
| decoupleR | v2.12.0 |
| tidyestimate  | v1.1.1  |
| pROC | v1.19.0.1 |
| glmnet | v5.0 |
| xgboost | v3.2.1.1|

The scripts were executed in the order indicated by the file name structure. 

Additional scripts used for statistics and figures are included in the following folders. 
Results generated by these scripts were used to produce the figures reported in the manuscript.

- `additional_scripts_figures/` 
- `ihc_statistics_and_figures/` 

### Input files

Required inputs include:

- Sample metadata (`sample_list_shortid.txt`)
- Gene-level read counts generated by STAR (`"raw_counts_all" directory`)
- Transcripts Per Million (TPM) counts generated by Salmon (`salmon_counts.csv`)
- Gene annotation files (`tx2gene.gencode.v36.pa_edited.csv`)
